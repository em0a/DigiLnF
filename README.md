## 🌐 Project Overview

**DIGI-L&F** is a modernized, full-stack digital logistics solution designed specifically for campus-wide physical kiosk hardware. It completely replaces traditional, error-prone paper logbooks with a touch-friendly terminal that enforces strict data integrity, user accountability, and transparent audit trails.

---

## 🏗️ System Architecture & Data Flow

The system operates on a cohesive, synchronized architecture where every user action triggers a secure chain reaction from the frontend UI straight to the local backend storage engine.
